# ⚙️ SPEC — Chatbot RAG (PostgreSQL)

---

## 1. 🏗️ Arquitetura

### Visão Geral
Sistema de perguntas e respostas baseado em documentos (PDF), utilizando abordagem RAG (Retrieval Augmented Generation) com armazenamento em PostgreSQL.

Fluxo:
Usuário → UI → Backend → Retriever → LLM → Resposta

---

## 2. 🧩 Stack Tecnológica

- Python 3.12+
- PostgreSQL
- Extensão pgvector (preferencial)
- OpenAI API ou Claude API
- Streamlit ou Gradio

## 4. 🔄 Pipeline RAG

1. Upload do PDF  
2. Extração de texto  
3. Chunking (divisão em partes)  
4. Geração de embeddings  
5. Armazenamento no PostgreSQL  
6. Recuperação de contexto relevante  
7. Geração de resposta via LLM  

---

## 5. 📄 Chunking

- Tamanho: 500 a 800 tokens  
- Overlap: 100 a 150 tokens  

Regra crítica: chunks devem manter contexto semântico.

---

## 6. 🧠 Embeddings

- Modelo: text-embedding-3-small (ou equivalente)  
- Dimensão: conforme modelo (ex: 1536)  

---

## 7. 🗄️ Armazenamento (PostgreSQL)

### Com pgvector (recomendado)

Tabela:

- id (UUID)  
- content (TEXT)  
- embedding (VECTOR)  
- metadata (JSONB)  

Consulta:

- Similaridade por cosine distance  
- Top-K: 3 a 5 resultados  

---

### Sem pgvector (fallback)

- Uso de full-text search (tsvector)  
- Busca por similaridade textual  
- Re-ranking com LLM  

---

## 8. 🔍 Recuperação

- Converter pergunta em embedding  
- Buscar top-k chunks similares  
- Aplicar threshold mínimo de similaridade  
- Retornar apenas contexto relevante  

---

## 9. 🤖 Geração de Resposta

Prompt obrigatório:

"Responda apenas com base no contexto fornecido.
Se a resposta não estiver no contexto, diga:
'Não encontrei essa informação no documento.'

Contexto:
{context}

Pergunta:
{question}"

---

## 10. 🚫 Controle de Alucinação

- Nunca responder fora do contexto  
- Sempre indicar quando não souber  
- Exibir trecho fonte utilizado  
- Limitar resposta ao conteúdo recuperado  

---

## 11. 🧪 Testes

### Unitários

- Chunking correto  
- Geração de embeddings  

### Integração
- Pergunta → resposta coerente  
- Resposta baseada no documento

## 12. ⚠️ Tratamento de Erros

- PDF inválido → erro controlado  
- Sem contexto relevante → fallback de resposta
